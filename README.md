# SmartFit Pro — Smart Watch E-Commerce Website

A modern, responsive smart-watch e-commerce frontend built with React and Vite.

## Features

- Responsive premium storefront design
- Product collection with category filters
- Product search
- Wishlist interactions
- Shopping bag / cart drawer
- Product pricing and ratings
- Newsletter subscription UI
- Mobile navigation
- Responsive layout for desktop, tablet and mobile

## Tech Stack

- React.js
- Vite
- JavaScript (ES6+)
- CSS3
- Lucide React
- Google Fonts

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

Developed as a frontend e-commerce project during a CodeBind Technologies internship.
